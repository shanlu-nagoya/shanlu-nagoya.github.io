MULTIPLE-ACCESS · CODING THEORY

Signature Code Theory for Multiple-Access Communication

When many users transmit at once over a shared channel, how can the receiver tell who sent what — without coordination, and with as little redundancy as possible? This project studies that question through code design for the multiple-access adder channel and its modern successor, unsourced random access.

Research threads

1. Uniquely decodable and signature codes for the adder channel

In the T-user multiple-access adder channel, the receiver observes the sum of all users' codewords. A signature code assigns each user a codeword set so that every sum is uniquely decodable. We developed recursive and generalized constructions of multiary (k-ary) signature codes, including error-correcting families for the noisy adder channel and constructions with arbitrary code length.

2. Learning-aided signature codes for fading channels

Classical constructions assume a noiseless or Gaussian sum. For Rayleigh-fading multiple-access channels, we combine signature codes with deep-learning decoders (DNN, BNN, and TISTA-based) to jointly identify active users and estimate their channels, and design the codes end to end.

3. Unsourced random access

In massive machine-type communication, all users share one codebook and the receiver only needs the list of transmitted messages. We improve coded compressed sensing schemes by raising the survival probability of messages through tree decoding and by increasing the maximum number of tolerable active users.

// 01  OVERVIEW概要

Project Overviewプロジェクト概要

This project investigates image sensor communication (ISC) using an LED propeller as a transmitter. When an LED-mounted propeller rotates at high speed, it generates a visible "light trail" pattern that can be captured by an image sensor camera. We develop theoretical models to characterize these light trail patterns and propose methods to prevent interference between multiple transmitters. 本プロジェクトでは，LEDプロペラを送信機として用いたイメージセンサ通信（ISC）を研究しています． 高速回転するLED搭載プロペラは，イメージセンサカメラで撮影可能な「ライトトレイル」パターンを生成します． 本研究では，このライトトレイルパターンの理論的モデルを構築し，複数の送信機間の干渉を防止する手法を提案します．

The proposed theoretical framework enables accurate prediction of light trail geometry, signal intensity distribution, and inter-symbol interference, providing a foundation for the design of reliable LED propeller-based ISC systems. 提案する理論的枠組みにより，ライトトレイルの形状・信号強度分布・シンボル間干渉の正確な予測が可能となり， 信頼性の高いLEDプロペラ型ISCシステム設計の基盤を提供します．
